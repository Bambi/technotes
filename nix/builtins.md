## Builtins & Library Functions
- `map`: apply a function on each element of a list (modify the list)
- `filter`: remove some elements of a list depending on a predicate
- `mapAttrs`: apply a function on each element of an attr-set (to modify the value)
- `mapAttrs'`: apply a function on each element of an attr-set (to modify the key & value)
- `filterAttrs`: remove keys of an attr-set depending of a predicate
- `list.findFirst`: returns the first list element which verify a predicate
- `list.drop`: remove the last n elements of a list
- `splitString`: split a string depending on a separator and create a list with each elements
- `concatStringSep`: create a string from a list of string elements
